# Bidline

Working name for phase-1 product: a narrow tool that turns a client brief + past case notes into a structured proposal outline, pricing table, and risk list for small creative/dev agencies.

Why this wedge:
- Buyers already pay for proposal labor.
- Public indie examples in adjacent workflow tools have reached four-figure MRR without ads.
- Scope is small enough to ship before asking for payment setup.

Not yet done (requires the account owner):
- Payment merchant (Stripe or Lemon Squeezy) and tax identity
- Domain and production hosting approval
- Any customer outreach from a real identity

Do not treat this file as a launched product.
